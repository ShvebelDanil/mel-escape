# Контекст проекта: Мэл: Побег из школы
**Жанр:** 3D Endless Runner (клон Subway Surfers)
**Стек:** JavaScript (ES6 Modules), Three.js, HTML5/CSS3.
**Среда:** Браузер (Яндекс.Игры), локальный запуск через Live Server.

## 1. Архитектура (Где что лежит)
Проект разбит на модули. Вот структура папки `/source/`:
- `main.js` — точка входа. Инициализация игры, подписка на события, запуск GameLoop.
- `engine.js` (или `core.js`) — настройка Three.js (Scene, Camera, WebGLRenderer, свет).
- `player.js` — класс игрока. Логика бега, прыжков, подкатов, смены полос, анимации.
- `level.js` (или `world.js`) — генерация бесконечного коридора, парт, спавн бутылок и препятствий (пулинг объектов).
- `physics.js` (или `collision.js`) — проверка столкновений (AABB или Sphere пересечения) между игроком и препятствиями.
- `input.js` — обработка клавиатуры (Стрелки) и свайпов (Touch-события).
- `ui.js` — обновление HTML-интерфейса (очки, бутылки, экраны смерти).
- `assets.js` — загрузка текстур и моделей (TextureLoader).

## 2. Архитектурные правила (Как файлы общаются)
- **Игровой цикл (Game Loop):** Находится в `main.js` (через `requestAnimationFrame`). Он вызывает метод `.update(deltaTime)` у Player, Level и т.д.
- **Глобальные переменные:** Избегаем. Используем импорты/экспорты или единый объект состояния `gameState` (очки, статус игры, скорость).
- **События:** Модули не зависят друг от друга жестко. Например, `input.js` не двигает игрока сам, он экспортирует нажатые клавиши, а `player.js` их читает.

## 3. Правила для написания кода (Промпт для ИИ)
1. **Пиши только в контексте нужного файла.** Не пытайся переписать всё, если нужно изменить только логику прыжка — меняй только класс в `player.js`.
2. Сохраняй стиль ES6 (import/export, классы, стрелочные функции).
3. Думай о производительности. Избегай создания новых объектов (через `new THREE.Vector3()`) внутри игрового цикла `update`, переиспользуй существующие (Object Pooling).
4. Отвечай только измененным кодом. Не пиши длинные текстовые объяснения, если я об этом не просил.
5. Если тебе не хватает контекста из другого файла (например, ты не знаешь, как выглядит объект препятствия из `level.js`), СТОП! Спроси меня: "Пришли файл level.js", не додумывай методы сам.
